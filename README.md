# Taller de Kotlin y Jetpack Compose

Curso interactivo en espanol basado en la organizacion del Taller Dart y Flutter, con un proyecto transversal llamado AutoFlow para administrar vehiculos.

La web se implementa en `index.html`, `styles.css`, `lessons.js` y `app.js`, sin compilacion ni dependencias de servidor. Contiene una ruta de Kotlin y una ruta de Android con Jetpack Compose, ejercicios, retos, snippets de codigo y simuladores en el navegador.

> Las practicas web simulan el resultado educativo. Para ejecutar codigo Kotlin o Android debe usarse Kotlin/JDK o Android Studio.

## Publicacion

En GitHub, abrir Settings > Pages, elegir **Deploy from a branch** y seleccionar `main` y `/ (root)`. Luego la web estara disponible en https://diln20.github.io/tallerKotlin/.
